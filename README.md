📝 Project Title: Text Area Character Counter
📖 Description:

A simple and interactive web app built using HTML, Tailwind CSS, and JavaScript.
This project allows users to type text inside a textarea while displaying a real-time character counter.
The counter updates dynamically, showing how many characters have been typed and how many remain out of the maximum limit (200).
If the user reaches the limit, a warning message appears and further typing is restricted.

⚙️ Features:

🧾 Real-time character counting

🚫 Restricts input beyond 200 characters

⚡ Instant feedback with live updates

🎨 Clean, responsive Tailwind CSS design

🧠 Tech Stack:

HTML5 – Structure

Tailwind CSS – Styling and layout

JavaScript (ES6) – Logic and interactivity
